# Swimming with Turtles

Open index.html with all supplied files and assets kept together. The activity also works on static website hosting without a build step.

The structure matches Mountain Biking: Pre-A, Pre-AA, A, AA and AAA levels; four story chapters with 2, 3, 4 or 6 cloze blanks each; current-page notebook questions and matching; a final turtle diagram with 3, 4, 6 or 8 labels. Maximum scores are 19, 23, 28, 38 and 52.

Choices have grab handles. Blue landing pads are larger than the tiles. Pads glow while targeted and flash after placement; this confirms placement for every answer and does not reveal correctness. A− and A+ adjust reading and answer text from 90% to 140%. Longer passages reflow into text parts within the same chapter so the activity stays within the screen.

The parent cards contain 40 topic words, eight on each of five Letter pages. They include simple definitions, cutting guides and no plot summary or character names. Print at Actual Size / 100%.

Voice starts disabled. Teacher access remains 259. Browser progress and exports are separate from Mountain Biking. Keep results downloads before resetting a camper's attempt.

Five story illustrations were created with the built-in image-generation tool. Prompt set: assets/IMAGE-PROMPTS.txt.
